# Настройка Vercel KV для Wishmakers

## Проблема
При создании и отправке списка появляется сообщение: "Не удалось сохранить список на сервер, проверь настройки Vercel KV"

## Решение: Настройка Vercel KV

Vercel KV — это хранилище данных (на базе Redis), необходимое для сохранения списков на сервере и их шаринга между пользователями.

### Шаг 1: Открой Vercel Dashboard

1. Зайди на https://vercel.com/dashboard
2. Войди в свой аккаунт
3. Выбери проект `wishmakersipon`

### Шаг 2: Создай KV Database

1. В меню проекта выбери **Storage** (или **Storage** в боковом меню)
2. Нажми **Create Database**
3. Выбери **KV** (Key-Value Database)
4. Введи имя базы данных (например, `wishmakers-kv`)
5. Выбери регион (ближайший к твоим пользователям, например, `iad1` для США)
6. Нажми **Create**

### Шаг 3: Подключи KV к проекту

После создания базы данных:

1. Vercel автоматически подключит её к проекту
2. Переменные окружения будут добавлены автоматически:
   - `KV_REST_API_URL`
   - `KV_REST_API_TOKEN`
   - `KV_REST_API_READ_ONLY_TOKEN`

### Шаг 4: Проверь подключение

1. Перейди в **Settings** → **Environment Variables**
2. Убедись, что переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` присутствуют
3. Если их нет — Vercel должен был добавить их автоматически при создании KV

### Шаг 5: Перезапусти деплой

После настройки KV:

1. Перейди в **Deployments**
2. Найди последний деплой
3. Нажми **Redeploy** (или сделай новый деплой через `npx vercel --prod`)

### Шаг 6: Проверь работу

1. Открой приложение
2. Создай новый список
3. Нажми "Поделиться"
4. Должно появиться сообщение об успешном сохранении (или просто работать без ошибок)

## Альтернатива: Проверка через CLI

Если хочешь проверить через терминал:

```bash
# Проверь переменные окружения
npx vercel env ls

# Должны быть:
# KV_REST_API_URL
# KV_REST_API_TOKEN
# KV_REST_API_READ_ONLY_TOKEN
```

## Важно

- **KV Database бесплатен** для небольших проектов (до 256 MB данных)
- **Данные хранятся 1 год** (TTL настроен в коде)
- **Все списки публичные** (в MVP версии)

## Если проблема остаётся

1. Проверь логи в Vercel Dashboard → **Deployments** → выбери деплой → **Functions** → выбери функцию `/api/lists`
2. Проверь, что переменные окружения доступны в production
3. Убедись, что KV Database создан и подключен к проекту

## Стоимость

- **Free план**: 256 MB данных, 30,000 операций чтения/дня, 10,000 операций записи/дня
- Этого достаточно для MVP и тестирования
