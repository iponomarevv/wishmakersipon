# Backend Setup для Wishmakers

## Настройка Vercel KV (Redis)

Для работы бэкенда нужно настроить Vercel KV:

1. **Создай KV Database в Vercel:**
   - Зайди в https://vercel.com/dashboard
   - Выбери проект `wishmakersipon`
   - Перейди в раздел **Storage**
   - Нажми **Create Database** → выбери **KV**
   - Назови базу (например, `wishmakers-kv`)
   - Выбери регион (ближайший к пользователям)
   - Нажми **Create**

2. **Подключи KV к проекту:**
   - После создания KV, Vercel автоматически добавит переменные окружения:
     - `KV_REST_API_URL`
     - `KV_REST_API_TOKEN`
   - Эти переменные будут доступны в Serverless Functions автоматически

3. **Проверь работу:**
   - После деплоя API endpoints будут доступны по адресам:
     - `POST /api/lists` - создать/обновить публичный список
     - `GET /api/lists/[id]` - получить публичный список
     - `PUT /api/lists/[id]` - обновить публичный список
     - `DELETE /api/lists/[id]` - удалить публичный список

## Как это работает

1. **При сохранении списка:**
   - Если список публичный (`isPublic: true`), он автоматически сохраняется в Vercel KV
   - Также сохраняется локально в Telegram Cloud Storage / localStorage

2. **При открытии по ссылке:**
   - Сначала проверяется локальное хранилище
   - Если список не найден локально, загружается с бэкенда (Vercel KV)
   - Список показывается в режиме просмотра (read-only)

3. **При удалении списка:**
   - Если список был публичным, он удаляется из Vercel KV
   - Также удаляется из локального хранилища

## Лимиты Vercel KV (Free Tier)

- 256 MB storage
- 30,000 requests/day
- Достаточно для небольшого приложения

## Troubleshooting

Если API не работает:
1. Проверь, что KV Database создан и подключен к проекту
2. Проверь логи в Vercel Dashboard → Functions
3. Убедись, что переменные окружения `KV_REST_API_URL` и `KV_REST_API_TOKEN` установлены
